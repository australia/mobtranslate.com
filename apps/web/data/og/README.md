# Share card assets

Read by `lib/og/card.tsx` when it draws the link-preview cards for dictionaries and words.

- `playfair-600.woff`, `inter-*.woff`: Playfair Display and Inter, Latin subset, from Fontsource 5.1.0. SIL Open Font License 1.1.
- `logomark-dark.svg`: `public/brand/logomark.svg`, recoloured for the dark card.
- The Australia outline in `lib/og/australia.json` is Natural Earth 1:50m (public domain), via world-atlas 2.0.2, projected at 26°S and simplified.

The homepage card, `public/og/mobtranslate-2026-10.jpg`, uses the same outline and fonts. Give a new card a new file name, because X keeps a card for about a week.
